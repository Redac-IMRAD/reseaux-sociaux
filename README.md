# Redac'IMRAD — réseaux sociaux

Page publique destinée aux étudiants arrivant depuis les réseaux sociaux.

## Adresse prévue

`https://redac-imrad.github.io/reseaux-sociaux/`

## Principe

Le HTML et le style restent stables. Les contenus courants sont centralisés dans `config.js` afin de pouvoir modifier facilement :

- les textes de présentation ;
- les avantages de l'accompagnement ;
- les offres ;
- les tarifs ;
- les liens d'achat ;
- la FAQ ;
- les appels à l'action.

## Fichiers

- `index.html` : structure de la page ;
- `styles.css` : présentation visuelle ;
- `config.js` : paramètres et contenus éditables ;
- `app.js` : affichage dynamique des paramètres.

## Important

Ne jamais stocker de secret, clé API privée ou donnée étudiante dans ce dépôt public.
